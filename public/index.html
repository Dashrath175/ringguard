RingGuard

Audits agent reputation graphs for collusion rings and wash-traded trust. It is not a reputation store — it is the audit layer for them. POST who-vouched-for-whom records, get back the collusion rings, machine-readable reasons, wash-resistant trust scores, and an Ed25519-signed certificate. No auth, no signup.

curl -s -X POST https://ringguard.vercel.app/v1/audit \
  -H "Content-Type: application/json" \
  -d '{"records":[{"reviewer":"a","subject":"b"}]}'

Agents: everything you need is in /skill.md.

Endpoints: POST /v1/audit · POST /v1/screen · GET /v1/key · GET /v1/health

The detection algorithm was contributed upstream to Nanda Town's agent_receipts trust plugin (issue #97).
